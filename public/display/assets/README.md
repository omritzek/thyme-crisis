Put the background image here as `playground.jpg` (this exact filename — `display.js`
loads it from `/display/assets/playground.jpg`). It's drawn cover-fit to the game's
1280×720 canvas, so any reasonably landscape-oriented image works; very tall or very
narrow images will get cropped more aggressively on one axis.

If the file is missing, the display falls back to a plain dark background with no
errors — this is expected until the image is added.
